# ASL Alphabet Translator

A real-time American Sign Language (ASL) alphabet recognition app. Hold a hand sign up to your webcam and it identifies the letter, building words and sentences as you go.

This is a proof of concept rebuilt from scratch, inspired by an older ARSL (Arabic Sign Language) project that relied on a pre-existing model rather than training its own. The goal here was to do it properly from the ground up — collect a dataset, extract features, train a classifier, and ship a working app — keeping the scope tight and the implementation transparent.

---

## How it works

### 1. Landmark extraction

Raw images are not fed to the model. Instead, [MediaPipe Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker) detects the hand in each image and extracts 21 key points (knuckles, fingertips, wrist). Each point contributes an (x, y) coordinate, giving a 42-dimensional feature vector per image. The coordinates are made wrist-relative and normalised to [-1, 1] so the model is invariant to hand position and size in the frame.

This is done once as a preprocessing step — `ingest/from_images.py` walks the dataset folder and writes every detected hand to `static_data.csv`.

### 2. Classification model

The classifier is a small dense neural network:

```
Input (42)  →  Dense(128, ReLU) + BatchNorm + Dropout(0.3)
            →  Dense(64,  ReLU) + BatchNorm + Dropout(0.3)
            →  Dense(32,  ReLU)
            →  Dense(N,   Softmax)          # N = 29 classes
```

Trained with early stopping on validation accuracy, then exported to TFLite with default optimisation for fast CPU inference. The `.tflite` file is what the live app loads.

### 3. Live app

The app runs two things in parallel:

- **Camera thread** — captures frames from the webcam, runs MediaPipe Hand Landmarker in live-stream mode, classifies each detected hand, and writes annotated JPEG frames to a shared buffer.
- **MJPEG server** — a minimal HTTP server on port 5001 that streams those frames to the browser as a standard `multipart/x-mixed-replace` feed. This keeps the video completely independent of the GUI framework.

The [Taipy](https://taipy.io) GUI on port 5000 handles the interactive side — the predicted letter, confidence, sentence builder, and settings. Prediction state is pushed to Taipy at ~5 Hz via `broadcast_callback`, separate from the video stream.

## Dataset

**ASL Alphabet** by grassknoted on Kaggle — 87 000 images across 29 classes (A–Z + `space`, `del`, `nothing`), 3 000 images per class, captured under varied lighting and hand positions.

Source: [kaggle.com/datasets/grassknoted/asl-alphabet](https://www.kaggle.com/datasets/grassknoted/asl-alphabet)

The dataset is included in this repo under `asl-alphabet/`.

## Quickstart

### 1. Install dependencies

```bash
cd asl-classifier
pip install -r requirements.txt
```

### 2. Extract landmarks from the dataset

Run cell **0** in `train_static.ipynb`, or directly from the terminal:

```bash
cd asl-classifier
python -m ingest.from_images \
    --source ../asl-alphabet/asl_alphabet_train/asl_alphabet_train \
    --out_csv   model/static_classifier/static_data.csv \
    --out_labels model/static_classifier/static_labels.csv
```

Processes ~87 000 images, takes 10–20 minutes. Writes `static_data.csv` (~87 000 rows × 42 features).

### 3. Train

Open `train_static.ipynb` from the `asl-classifier/` directory and run all cells. Trains in a few minutes on CPU, faster with a GPU. Saves `static_classifier.hdf5` and exports `static_classifier.tflite`.

### 4. Run

```bash
cd asl-classifier
python app_taipy.py
```

Open **http://127.0.0.1:5000** in your browser.
